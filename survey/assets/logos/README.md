# Logo set

Generated by `survey/tools/build_logos.py`.

- Brand marks: [simple-icons](https://github.com/simple-icons/simple-icons) (CC0-1.0) and
  [@lobehub/icons](https://github.com/lobehub/lobe-icons) (MIT). The marks are trademarks of their
  owners and are used here only to identify the products discussed in the survey.
- Monogram tiles (`e2b`, `daytona`, `sglang`, `strands`, `firecracker`): brands without a mark in
  either package; the figures print the full name under each tile.
- `icon-*`: generic line icons drawn for the survey.
