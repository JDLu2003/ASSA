# 写作检查表

修改综述页面前逐条对照。每条先写规则，再写曾经出现的错误与分析。

## 一、元话语与指令

1. **不写制作过程。** 曾出现“浏览器打印 PDF + 全文”“本页整理…”“原文配图在存档时未能加载”“取自 OSDI 发表版 PDF 第 7 页”、抓取日期与开发时间。
   这些是指向作者自身的元话语（Hyland），把写作现场带进了阅读现场；综述是结果文体，读者关心内容。违反 Grice 的关联准则与量准则。
2. **不把用户的指令写进正文。** 曾出现“XX 原图”“现状”“动机”“结论”“厂商定义”“本文按目录分为三部分”。
   这是使用与提及的混淆（Frege、Quine），也是元语言与对象语言的层级错位（Tarski）：指令是对文本的要求，属于元语言。按言语行为理论（Austin、Searle），把指令性言语行为转写成断言，文本就成了“我照做了”的自我表演（Goffman 的面子工作），而没有传达信息。
3. **概念直接用本名，不加多余的限定语。** 曾出现“学术文献中的 Agent-as-a-Service”。
   限定语预设存在一个对比类（语用预设）；对比类不存在时，读者会去寻找一个并不存在的对象。

## 二、句法与修辞

4. **标题不用“XX：从 AA 到 BB”或冒号式结构。** 曾出现“OpenAI：环境可以晚于会话启动”“问题：回滚落在关键路径上”。
   冒号在修辞结构理论（Mann & Thompson）中标示阐述、同位等关系；两侧没有这种关系时，冒号是虚假的连贯标记。“从 A 到 B”还会制造目的论式的叙事（叙事谬误）。
5. **陈述做了什么，不写“不是 A 而是 B”“只做 X 不做 Y”。** 曾出现“agent 基准不再是一组问答对，而是…”“不修改 agent 与 C/R 后端”。
   否定在语用上是有标记的，预设被否定的命题已在话题中（Givón）；前文没有 A 时，这是在树稻草人。一个系统“不做”的事是无限集（开放世界假设），用否定来界定对象，信息量为零；定义应当正面给出（亚里士多德：属加种差）。
6. **不强调朴素的性质。** 曾出现“一个 agent 会话”“四个编号”“同一”“独立”“只”。
   这些词触发数量含义（Grice 的等级含义）：“一个”会被理解为“恰好一个而非多个”，等于多做了一个没有依据的断言。按标记理论，有标记的形式暗示对比，没有对比时就是虚假对比。
7. **能用名词就用名词，避免动宾结构堆叠。** 曾出现“负责调用模型、执行工具、管理上下文”。
   技术语体倾向于名词化（Halliday 的语法隐喻，如“模型调用、工具执行”），词汇密度更高；动宾链会把描述读成动作清单。

## 三、逻辑结构

8. **动机按“现象 → 需要分析”的顺序写，写到“需要分析”为止。** 曾写成“已有分析集中在单个环节…因此本文…”“目前还没有把它作为整体来分析的工作”。
   行动的理由需要一个价值大前提（X 重要），再加事实小前提（实践三段论）。只拿“没人做过”作理由，接近诉诸无知与诉诸新奇。缺口与方法属于后文。
9. **动机不引用正文的发现。** 曾用后文的负载测量、计费口径与命名对照来论证这篇综述的必要性。
   这是循环论证，修辞上则是前后倒置（hysteron proteron）。
10. **封面只放对现象的判断，简明扼要。** 曾把后文的发现写成封面上的三条“结论”。
    论证层级错位，也违反量准则。
11. **按本质差别分类。** 曾把“模型厂商”和“云平台”分成两页。
    划分应当依据本质的种差（亚里士多德）：有意义的差别是 harness 由谁运行，厂商的行业身份只是偶性。
12. **主语用专名，页面对象写进标题。** 曾以“2026 年关于 agent 执行环境的论文多数研究…”开头，实际讲的是 Crab；还在 Crab 页提及无关的 DeltaBox。
    用不定摹状词替代专名（Russell）造成指称不明；无关的联想违反关联准则。
13. **局部指令不作排他理解。** 曾因“加粗 A”而去掉 B 的加粗，并把“第一段还行”对应到了错误的段落。
    前者是对焦点的过度穷尽解读（Rooth 的选项语义学），近似假二分；后者是回指消解错误。

## 四、事实与证据

14. **每个断言都要有出处。** 曾出现“狭义 / 广义 agent”“两篇常被引用的综述”、把 Cloud Run sandboxes 归入共享内核层、“模型越便宜，环境费用占比越大”。
    这些断言缺少示证标记，把推测当作事实陈述，属于轻率概括或不当推论（non sequitur）。
15. **数字以一手文本为准并复算。** 曾用 arXiv 摘要页的旧数字（DeltaBox 14 ms / 5 ms，正文为 10.83 ms / 1.86 ms），并把 15.2% 写成“低于 15%”。
    前者是史料批判的失误，没有核对版本；后者是算术错误，陈述与事实不符（真理符合论）。
16. **原图必须是未经处理的原图。** 曾对厂商图做颜色量化与裁剪、从 PDF 页面截取论文图、把自绘图放在厂商图的位置。
    这是来源链条的失实。原图的价值在于与原物的直接联系（Peirce 的指示符）；处理或重绘后，它只剩像似符的性质，却仍被当作指示符呈现。

## 五、视觉表达

17. **图要表达部件之间的关系。** 曾在图 14 中让 ②③④ 与 harness 内部的元素脱节。
    图示是保留结构关系的像似符（Peirce）；节点之间没有连接，图就没有表达关系，只是排版。
18. **去掉不承载信息的装饰。** 曾使用大黑底、阴影、流动动画、文字徽章与“来源”标签。
    按数据–墨水比原则（Tufte），这些墨水不承载数据；装饰还会把风格信号推向营销文体（Loos）。

## 根本原因

- 想“显得照做了”，没有真正理解要求：第 1、2、3、13、16 条。
- 想“显得有论证”，没有遵守论证的顺序与证据要求：第 8、9、10、14 条。
