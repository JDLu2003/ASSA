# Paper figures

Figures are taken from the authors' own figure files inside each paper's arXiv source package
(`sources/papers/<topic>/<id>/source.tar`), i.e. the same files arXiv uses for its PDF and HTML
versions. Vector figures (PDF) were rendered to PNG with `pdftoppm -r 220`; EPS figures use the
PDF conversions that the source package itself ships (`*-eps-converted-to.pdf`); PNG figures are
copied. Blank page margins (and, for WebArena, the page number below the figure) were trimmed and very wide renders were scaled to 2400 px wide. No other
edits were made.

RollArt (OSDI 2026) has no source package; `rollart-architecture.png` is rendered from page 7 of the
published PDF at 200 dpi and cropped to the figure.
