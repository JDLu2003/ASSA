The Agents API runs the Codex harness and manages the underlying agent infrastructure so you can focus on what your agents do.
It includes automatic context compaction, multi-agent orchestration, programmatic tool calling, and support for MCP servers. See
Architecture.

The Agents SDK gives your application control over deployment, storage, approvals, and runtime integration. Its runner handles the
agent loop and handoffs. See Running agents.
