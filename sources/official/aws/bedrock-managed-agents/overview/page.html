      What makes Bedrock Managed Agents different?

      Frontier intelligence

      Bedrock Managed Agents combines OpenAI models with the Codex harness to preserve context, coordinate tools and specialized agents, and guide complex assignments across multiple steps and decisions.

      Secure from day one

      Each agent operates with its own AWS identity and defined permissions, helping you control the resources it can access and the actions it can take. The agent runtime and model inference remain inside AWS.

      The breadth and scale of AWS

      Bedrock Managed Agents runs on globally available AWS infrastructure, close to the data, applications, and services your agents need. It connects directly to AWS compute and data services your teams already use and rely on.

      Designed to work with AgentCore

      Bedrock AgentCore is the open platform to build, connect, and optimize agents at scale using any model and framework. It provides the default compute environment for Bedrock Managed Agents. As your agent footprint grows, you can draw on broader AgentCore capabilities, including authorization, agent and tool discovery, observability, evaluation, and more.
